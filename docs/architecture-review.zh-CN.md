# Machine Learning Handbook：课程与架构审查

> 后续实施说明：本报告记录重构前的仓库状态。原 `pages/` 已迁至 `legacy/streamlit/pages/`；新版结构、启动方式和当前完成范围见 [实施记录](migration.md) 与 [README](../README.md)。

审查日期：2026-10-04（Australia/Melbourne）。范围：当前工作目录全部 13 个 Python 源文件，约 1,900 行；官方框架文档与交互教学案例。以下是源码审查、独立数值复核和架构建议，并非上线后的性能评测或学生学习效果评测。

## 1. 建议先做的决定

这个项目已经有可用的教学素材，尤其是 OLS/MLE、正则化几何、SVM 和 EM。下一阶段应把它发展为有学习路径的交互教材，并把教学内容、算法计算、实验状态和页面展示分开。

默认建议：**Next.js + React + TypeScript，MDX 编写课程，浏览器负责轻量实验，Python/FastAPI 承担需要科学计算库的实验**。这是基于希望继续增加课程、练习、进度和实验功能的假设。第一版不必引入账号、数据库或任务队列。

如果确定长期只做公开教材和独立实验，**Astro + React islands + MDX** 同样合适，且是更精简的选择。如果维护者希望坚持 Python，则先改良 Streamlit，或用 marimo 制作代码实验；这两条路线的迁移成本更低，但需要接受不同的页面与交互组织方式。

框架不会自动修复教学错误，也不会自动产生设计品质。优先级应为：正确性 → 学习路径 → 统一实验体验 → 视觉设计 → 扩充算法。

## 3. 每个教程的评价

### 3.1 OLS / MLE — `pages/linear_ols.py`

**优点**：能控制真实截距、斜率、噪声、样本数；对照真实线和拟合线；展示 OLS 与高斯 MLE 的关系、残差分布、系数标准误和检验结果。是很好的统计入门核心素材。

**不足**：

- 第 34 行 `np.random.seed()` 使任何控件交互都重新抽样，学生不能清楚区分参数变化和随机样本变化的影响。
- 第 79 行“点到直线的垂直距离”容易被理解为几何最短距离；这里应明确为沿 y 轴的残差。OLS 在观测向量空间中的正交投影是另一种解释。
- 第 86 行把“求解 OLS”与“估计量具有无偏等性质所需的假设”混在一起；应区分最小化目标、满秩下的唯一解、条件均值为零，以及正态误差下的精确推断。
- 只有残差分布图，尚不能称为完整诊断；缺少残差对拟合值、QQ 图、杠杆点、异常值和置信区间/预测区间。
- p 值、显著性星号和 R² 缺少解释，容易让初学者误认为显著就是有实际价值、训练 R² 越大就越好。

**改法**：固定 seed；单独提供重新抽样；可拖动数据点；同步画残差线段和 RSS；允许切换异方差/离群点/非线性数据。先讲预测与误差，再展开推断。

### 3.2 梯度下降 — `pages/linear_gradient.py`

**优点**：手写迭代清晰，起点、学习率和迭代次数可调，等高线和轨迹容易建立几何直觉。

**不足**：

- 演示的是 `J(x,y)=x²+2y²`，尚未连接到上一课真实线性回归的 RSS；需明确这是优化器示意实验。
- 第 72 行 `learning_rate > 0.15` 就报告震荡，但当前最大值 0.2 不能产生该函数的坐标符号交替或发散。
- 没有单步、暂停、回放、损失曲线，也没有特征尺度/条件数实验。

**数值复核**：更新倍率为 `1−2η` 和 `1−4η`。在 `0<η≤0.2` 时二者均非负且小于 1；y 方向在 `η>0.25` 才开始符号交替，整体收敛要求 `0<η<0.5`。`η=0.5` 通常不能收敛，`η>0.5` 对非零 y 初值发散。

**改法**：把提示绑定真实轨迹；扩展学习率范围并设安全显示范围；加入一步一算；随后扩展到回归损失、特征标准化、SGD/Momentum/Adam。

### 3.3 Ridge / Lasso — `pages/linear_ridge.py`

**优点**：圆与菱形的几何解释有价值；做了特征标准化与目标中心化；展示 OLS 与正则化解；强制坐标等比例避免圆变形。

**不足**：

- 第 73 行实际给 Lasso 的 alpha 是滑块的 0.1 倍，页面未说明；而 sklearn 的 Ridge 与 Lasso 损失归一化本身也不同，因此同一滑块不能直接理解为同尺度比较。
- 页面介绍声称包括系数收缩路径，但当前只画一个参数点；缺少验证误差和交叉验证，尚未证实“防过拟合”。
- 第 80 行开始的网格计算对 10,000 个参数组合逐个遍历全体样本，两个图重复生成相同 RSS 网格。可改用 `yᵀy−2wᵀXᵀy+wᵀXᵀXw` 批量计算并复用。
- alpha=0 应切换 OLS，而非直接让 Lasso 的坐标下降处理零惩罚。
- 数据集提示提及 PCA，实际没有 PCA；加州房价注释写房龄，实际列名和索引对应 AveRooms。运行时下载数据也需缓存/失败处理。

**改法**：明确统一教学目标，例如 `RSS/(2n)+λR(w)`；对应 Ridge 的库参数为 `2nλ`，Lasso 为 `λ`。这统一的是目标表达，不能据此声称 L1/L2 的数值惩罚强度完全等价。添加系数路径、相关性旋钮、验证集曲线和 Elastic Net。

官方目标函数依据：[Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)、[Lasso](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Lasso.html)。

### 3.4 Logistic Regression — `pages/logistic.py`

**优点**：伯努利分布、log-odds、sigmoid、似然到线性边界的连接比较完整；特征空间与得分空间的双视图很好；误分类高亮有教学价值。

**不足**：第 41–42 行指标来自训练集；实际训练含正则项，推导只有无正则似然；C 应标为正则化强度的倒数；没有阈值实验、混淆矩阵或不平衡分类；第 67 行 eta/z 符号不统一。页面仅实现二分类，应避免把这一实现限制当成逻辑回归的全部能力。

**改法**：固定训练/验证/测试数据；调整阈值同时更新混淆矩阵、precision/recall；展示单样本 log-loss；随后补 ROC/PR、校准和 softmax。

### 3.5 Naive Bayes — `pages/bayes.py`

**优点**：先验、似然、后验与概率场结合；实现短，适合作为生成式与判别式模型的对照。

**不足**：第 36 行应写“给定类别后的条件独立”；高斯参数应带类别和特征两个索引 `μ_kj, σ²_kj`；并未画出各类条件密度椭圆，主要画的是后验概率；缺少先验变化与相关特征对假设的影响。“边界是二次曲线”应加一般情形的限定，特殊参数可退化为线性等情况。

**改法**：用一个样本逐步展示 `log prior + Σ log likelihood → posterior`；加入类比例与相关性控件；再做 Multinomial/Bernoulli NB 的文本或离散特征案例。

### 3.6 SVM — `pages/svm_app.py`

**优点**：有多种数据集和核；支持向量高亮；原始/对偶推导较完整；3D 图明确解释为决策函数地形，避免把它冒充真实高维特征空间。

**不足**：

- 初学者过早遇到拉格朗日乘子，缺少“拖一条分界线，比较间隔”的入口。
- 第 54 行把大 C 直接称为硬间隔不严谨；不可分数据并不因 C 变大就成为硬间隔问题。
- 第 179 行的注释把 decision_function 当几何距离；未经范数归一化的决策得分不能直接等同欧氏距离，核模型更需明确空间。
- 理论中的 ±1 标签与图中 0/1 标签应解释映射；Sigmoid 核也不应直接等同一个完整神经网络模型。
- 没有标准化实验、测试误差或 C/gamma 联合比较。

**改法**：分“间隔直觉 → 软间隔 → 核 → 对偶”四层；点击点展示其支持向量身份和 margin violation；加入参数热图和验证集。图表属性需在锁定的 Plotly 版本上验收，不根据旧版本印象断言其无效。

### 3.7 决策树 — `pages/tree.py`

**优点**：树结构和二维分区相互补充；深度与 Gini/entropy 控件直观；适合作为树模型家族入口。

**不足**：没有展示一次分裂的候选阈值及左右子节点加权不纯度；深度上限是预剪枝，不是完整的剪枝教学；训练集上的边界不能证实过拟合；深树被塞进固定 6×4 图中，可读性需浏览器验证。

**改法**：先让学生选择一刀，再比较算法选择；树节点与数据区域联动；加入训练/验证误差曲线、min_samples_leaf、成本复杂度剪枝以及回归树。

### 3.8 Bagging — `pages/ensemble_bagging.py`

**优点**：单树与集成可切换；引入 Bootstrap 和相关性对集成方差的影响，适合作为随机森林的前置课程。

**不足**：

- 第 39 行 `sign(sum(h_t))` 未声明 ±1 编码，与当前 0/1 类别不能直接对应。
- 当前树基学习器具有 predict_proba，sklearn 实际按平均预测概率取最大类，和硬多数投票未必相同。
- 方差公式对等方差、等相关的数值预测平均有假设，不能直接当离散分类输出的一般方差公式。
- 没有看到 Bootstrap 抽样与各树贡献；单一数据集的一幅图不能证明方差下降，边界也不保证更平滑。

**改法**：展示有放回抽样、重复/未入袋样本、各树概率和聚合；以多次重采样比较预测波动；增加 OOB 与验证误差。[BaggingClassifier 官方聚合规则](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.BaggingClassifier.html)。

### 3.9 Random Forest — `pages/ensemble_rf.py`

**优点**：明确提出特征随机性和去相关；概率场适合展示集成预测的不确定程度。

**不足**：核心机制 max_features 无控件；只有两个特征，难展示随机子空间效应；第 67 行“圆润边界类似核方法”容易把绘图插值当算法性质。有限棵轴对齐树的聚合仍是分片常数函数；平滑的等高线外观不能说明底层函数连续。

**改法**：增加 max_features；和同数据、同深度、同树数的 Bagging 并排对照；展示树间预测相关性、OOB 与置换重要性，并说明特征重要性不等于因果效应。

### 3.10 EM / GMM / Poisson mixture — `pages/stat_em.py`

**优点**：手写 E/M 步；隐变量、观测似然与完全似然讲解有深度；均值轨迹和 Poisson mixture 让 EM 超越单一 GMM 案例，是项目特色。

**不足**：

- 第 32 行把标为标准差的 cluster_std 直接填到协方差矩阵，实际标准差是其平方根。
- E/M 在一次 step 内完成；颜色使用 argmax 丢掉软责任度；图中责任度对应更新前参数，而均值/协方差已更新，需要明确阶段。
- 没有 log-likelihood 曲线、收敛判定、多初值比较；生成簇数与拟合簇数绑定，不能展示模型错设。
- 固定 20 次循环并 sleep，总人为等待约 10 秒；没有暂停、回退、持久状态。
- 直接概率归一化加 epsilon 是简化实现；应采用 log-sum-exp，并处理空分量/协方差退化。训练密度加了 jitter，绘图密度没有同样保护，是潜在稳定性风险，未声称已触发崩溃。
- `n_samples // K` 会使实际样本数少于滑块值，例如 N=100、K=3 只有 99 个。

**改法**：E/M 分步状态机、责任度色彩混合、似然曲线、可拖动初始中心；区分真实 K 与拟合 K；补完整的 π、μ、Σ 更新，以及局部最优和 GMM 奇异性的解释。Poisson mixture 留作进阶支线。

### 3.11 MCMC — `pages/stat_mcmc.py`

**优点**：手写接受/拒绝循环；双峰目标、trace、直方图和接受率放在一起，具备一个采样入门实验的基础。

**不足**：

- 第 12、15、49 行允许 burn-in 超过链长度，导致空样本；N=100、burn-in=100 也只剩 1 个状态，因为列表包含初值。
- 第 125–130 行仅凭建议步长宣称 mixing well；接受率也不能单独判定收敛。
- 实现是对称高斯建议下的随机游走 Metropolis；讲一般 MH 时应补建议分布比值，并解释此处为何约掉。
- 实际目标是已归一化的高斯混合；可以用于演示，但应讲清“算法只需要比例密度”和“例子恰好知道归一化密度”的区别。
- 缺少多链、ACF、ESS、R-hat 与 Monte Carlo 误差；高阶诊断需循序引入，也不能包装为收敛证明。
- 文案中的 mode collapse 应改为混合差/跨模态困难。

**数值复核**：复现当前循环，seed=42，N=100，步长 0.5，初值 0，保留第 10 步之后的状态，没有一次符号跨越，负半轴占比为 0，而界面分支会报告 mixing well。这是对自动结论的直接反例，并非完整收敛研究。

**改法**：限定 burn-in 与样本长度；展示候选点、接受概率和拒绝停留；基于实际链输出诊断；加入多链对照和估计量 Monte Carlo 误差。进阶再引入 Gibbs/HMC。

## 4. 跨页面共性问题及修复顺序

### 先修正确性

1. 梯度下降震荡警告与滑块范围不一致。
2. MCMC 空样本和未经诊断的成功提示。
3. EM 标准差/方差含义不一致。
4. Ridge/Lasso 目标函数与参数标识不一致。
5. 训练集指标需要显式标注，涉及泛化结论的实验增加独立验证。
6. LaTeX 字符串被 Python 转义：AST 检查已发现 OLS 第 84 行的 `\beta` 变成退格控制符，MCMC 第 59 行 `\frac` 变成换页符，第 64、69 行 `\alpha` 变成响铃符。`\theta`、`\tilde` 等也可能包含制表符；统一 raw string 或将正文迁出 Python。

### 再补教学闭环

- 当前首页目录仅列 SVM 和线性模型，与实际导航脱节；由一个课程注册表生成目录、前置知识、上下节、搜索和翻译状态。
- 基础统计缺失，而首页先出现逻辑回归与 SVM，不符合刚入门的定位。
- 11 页主要是“看推导、调滑块”，缺少“先预测 → 做实验 → 解释结果 → 检查理解”的任务。
- 全站中文为主，英文括注不是国际化；应按完整语言版本组织，公式符号、术语、控件、提示、图表文字均同步翻译。
- 大量固定双栏和高图表不等于移动端友好。当前未做实机验证，不给虚构的可访问性或性能分数。
- 正确结论必须来自当前实验数据；把固定的“更平滑”“混合良好”等结论改为可验证的观察提示。

## 5. 应补哪些算法、模型和前置课程

新增顺序依据是前置依赖与教学价值，不是热门程度。

| 优先级 | 模块 | 要解决的学习缺口 | 建议的核心交互 |
|---|---|---|---|
| P0 | 概率、期望、方差、条件概率、贝叶斯公式 | 为似然、NB、EM、MCMC 建立入口 | 抽样、先验到后验更新、二维条件概率 |
| P0 | 向量、点积、投影、导数、梯度、协方差 | 为线性模型、优化与 PCA 补数学桥梁 | 拖动向量、投影、局部斜率 |
| P0 | 抽样分布、CLT、置信区间、Bootstrap、MLE/MAP | 区分数据、参数、估计和不确定性 | 重复抽样与区间覆盖率 |
| P0 | 数据拆分、预处理、泄漏、指标、交叉验证、偏差方差 | 让学生正确使用所有后续模型 | 数据泄漏反例、固定测试集、学习曲线 |
| P1 | kNN 分类/回归 | 提供非常直观的非参数基线 | 拖动查询点、邻居投票、k 与边界 |
| P1 | 多项式回归 + Elastic Net | 衔接拟合复杂度、正则化和泛化 | 次数与训练/验证误差、系数路径 |
| P1 | K-means / K-means++ | 为 GMM 与 EM 补前置 | 逐步分配/更新、拖中心、坏初始化 |
| P1 | PCA / SVD | 当前没有降维主线 | 旋转投影轴、方差与重建误差 |
| P1 | AdaBoost、梯度提升树 | 补全 Bagging 之外的集成思想 | 逐轮残差或负梯度拟合、学习率、早停 |
| P1 | 感知机 → MLP → 反向传播 | 建立神经网络基本概念 | XOR、激活、链式法则、梯度流 |
| P2 | DBSCAN / 层次聚类 | 展示非球状簇、噪声点和另一种聚类组织 | epsilon/min_samples、树状图 |
| P2 | LDA/QDA、贝叶斯线性回归、Gaussian Process | 连接生成式分类与预测不确定性 | 协方差假设、后验、预测区间 |
| P2 | Poisson GLM、softmax、多分类评价 | 扩展已有回归/分类体系 | 链接函数、多分类概率、指标 |
| P2 | 时间序列基线、时间切分、异常检测 | 补常见数据科学应用 | 滚动回测、季节基线、异常阈值 |
| P3 | CNN、Attention/Transformer、推荐、强化学习 | 独立进阶路径 | 卷积窗口、注意力权重、小环境策略 |

XGBoost/LightGBM/CatBoost 可作为梯度提升之后的实践扩展，不必首期各建一个重复演示页面。t-SNE/UMAP 放在 PCA 与距离概念之后。首期无需为了“全面”同时加入所有深度模型。

推荐学习路线：数据与概率 → 抽样与估计 → 线性回归 → 优化与正则化 → 评价方法 → kNN/Logistic/NB → 树与集成 → 聚类/PCA → 概率模型与 EM → MCMC；神经网络形成另一条进阶支线。

## 6. 页面应如何变好看、变好学

统一课程模板：学习目标与前置知识 → 一个具体问题 → 可操作的直觉实验 → 数学推导 → 代码实现 → 常见失败情况 → 自测与下一课。

建议采用阅读型设计：稳定字号与行长、克制配色、公式留白、较少装饰性 emoji；教学用颜色保持语义一致，例如训练/测试、真值/估计各有固定色和线型，不只靠红绿区分。

桌面端用课程导航、阅读正文和随文实验区；手机端转单栏，控件放在图旁或可展开面板，避免让学生反复进入侧边栏。图表需要文字结论、数据表或可访问的替代说明；公式输出保留 MathML，交互支持键盘和减少动画。

最值得做的功能：

- 单步、播放、暂停、回退和重置；播放只是浏览计算快照，不用后端 sleep 驱动动画。
- 鼠标/触摸添加和移动数据点；显示该点如何改变模型。
- 相同数据和 seed 下的模型并排对比；比较条件显式固定。
- URL 保存参数、seed 和算法版本，分享后能复现实验。
- 按需展开的直觉/公式/代码层；中英完整切换；术语搜索。
- 解释型小测和预设挑战，例如“把训练准确率升高后，测试表现一定变好吗”。
- 首期本机保存阅读进度；有跨设备需求时再接账号与数据库。

可参考 [Seeing Theory](https://seeing-theory.brown.edu/) 的概率统计课程组织，以及 [TensorFlow Playground](https://playground.tensorflow.org/) 的实验控件、网络视图与训练反馈。这里借鉴的是学习机制与信息组织，不要求照搬视觉样式。

## 7. 技术栈比较

| 路线 | 对本项目的长处 | 成本/边界 | 建议 |
|---|---|---|---|
| 改良 Streamlit | 最大程度复用 Python；最快修复课程；已有科学计算生态 | 高度定制的手势、布局、多语言内容和复杂实验状态仍需额外工作 | 低成本过渡方案 |
| marimo | Python 反应式实验，适合可编辑代码与可复现课程 | 仍需另行规划课程网站的导航、内容与产品能力；WASM 兼容性要逐页确认 | 代码实验附录或 Python 优先方案 |
| Astro + React + MDX | 正文为静态 HTML，交互组件按需加载；适合公开教材 | 跨页面复杂业务需要自己组织；加入完整学习平台能力要继续设计 | 公开教材优先时首选 |
| Next.js + React + TypeScript + MDX | 内容、课程路由和交互可共存，后续扩展进度/练习/账户的组织空间大 | 需维护 JS/TS 工程、服务端/客户端边界与依赖 | 按“长期学习平台”假设的默认建议 |
| 纯 React + Vite SPA | 专注实验应用，结构直接 | 教材预渲染、搜索可发现性、内容路由需要额外安排 | 实验室子应用可用 |

以上是针对本项目的工程判断，并非官方性能排名。依据：[Streamlit fragments](https://docs.streamlit.io/develop/api-reference/execution-flow/st.fragment)、[marimo WASM](https://docs.marimo.io/guides/wasm/)、[Astro islands](https://docs.astro.build/en/concepts/islands/)、[Next.js MDX](https://nextjs.org/docs/app/guides/mdx)。Streamlit 支持局部重跑，不能简单说所有交互都必然导致整个应用重算；当前源码尚未采用这一机制。

### 默认栈的职责

- **Next.js / React / TypeScript**：课程路由与 UI；正文预渲染，实验是独立客户端组件。Next 支持静态导出，但采用纯静态部署时要遵守其不支持的服务端功能边界。[静态导出](https://nextjs.org/docs/app/guides/static-exports)。
- **MDX + KaTeX**：正文与公式；用受控组件嵌入实验。作者维护可信的仓库内容，不让普通用户提交可执行 MDX。[MDX](https://nextjs.org/docs/app/guides/mdx)、[KaTeX 输出选项](https://katex.org/docs/options.html)。
- **Tailwind CSS + shadcn/ui**：实现统一间距、颜色、导航、表单和弹窗；组件基础不等于完整网站自动通过无障碍验收。[shadcn/ui](https://ui.shadcn.com/docs)。
- **SVG/Canvas + 少量 D3**：拖点、梯度箭头、投影、树分裂等定制教学图；React 管 UI，D3 负责尺度和几何计算，避免双方同时管理同一 DOM 子树。[D3](https://d3js.org/what-is-d3)。
- **Plotly.js**：需要等高线、3D 或快速迁移的实验；保留已有图形思路，按需加载，不要求第一天全站改写图表。[React 集成](https://plotly.com/javascript/react/)、[Next 懒加载](https://nextjs.org/docs/app/guides/lazy-loading)。
- **Python + FastAPI + NumPy/SciPy/sklearn/statsmodels**：复用科学计算和统计推断；API 返回数值与诊断，前端决定如何展示。
- **PostgreSQL（后续）**：跨设备进度、练习尝试、共享实验记录。公开阅读与基础实验不依赖登录。

### 不同计算放在哪里

| 计算类型 | 建议执行位置 | 原因 |
|---|---|---|
| 简单梯度下降、kNN、K-means、小型 OLS 几何 | TypeScript Web Worker | 即时互动、减少网络往返；以 Python 参考输出做一致性检查 |
| 初期 SVM、RF、统计推断、EM/MCMC 批次计算 | Python API；部分预设也可预计算 | 保留成熟库与现有知识，减少重写风险 |
| 学生修改短 Python 示例 | 按需 Pyodide Worker | 代码在浏览器运行；验证包兼容性、下载体积与设备内存 |
| 长计算、多模型批量实验 | 后续独立进程/任务队列 | 只有需求和负载证明必要时增加 |

Pyodide 在 Worker 中运行可以避免阻塞 UI，但不是首次加载和所有依赖兼容性的免费解决方案。[官方 Worker 文档](https://pyodide.org/en/stable/usage/webworker.html)。FastAPI 的 async 不会自动加速 CPU 密集训练；CPU 工作需进程隔离/并行或任务执行层。[FastAPI 并发与并行](https://fastapi.tiangolo.com/async/)。

第一版采用“静态正文/CDN + 浏览器轻实验 + 一个 Python 计算服务”即可。Python 只提供受限、定义好的算法请求；控制样本数、网格分辨率、迭代次数、超时与并发。任意用户 Python 代码不进入普通计算 API。跨区域延迟通过本地计算、固定 seed 缓存和按需请求降低，实际部署位置和费用待流量/地区需求明确后评估。

迁移第一步可以只建立 `content/`、`python/ml_handbook/` 和一个 web 应用；不必为了目录形式立即拆成多个发布包。

课程元数据至少包括：`id, slug, locale, title, prerequisites, objectives, level, labId, contentVersion`。一个注册表生成首页、导航和上一课/下一课；语言切换保留课程身份，翻译缺失明确提示。

实验请求至少包括：`algorithm, algorithmVersion, datasetId, datasetVersion, seed, params, requestId`。数据点编辑后，需要传受限数组或保存数据快照，单凭 seed 不足以重现用户编辑。

结果至少包括：`parameters, predictions, metrics, snapshots, diagnostics, warnings`。EM 的每个 snapshot 标注 E/M 阶段；MCMC 区分 proposal 与 retained state；指标标注 train/validation/test。

状态机采用 `idle → running → paused/completed/error`。后端或 Worker 一次生成适量快照，前端逐帧播放。参数变化取消旧请求，或按 requestId 忽略迟到结果。缓存键包含数据、seed、算法版本和参数；不要把用户语言作为数学结果缓存的必需部分。

首批选 OLS 是为了验证拟合/统计图，Logistic 验证分类边界与评价，K-means 验证迭代动画。三种交互形态跑通后再批量迁移，能降低做完整站后才发现接口不合适的风险。

必要的验证应围绕数学和学习行为：OLS 与参考解一致；梯度下降在稳定区间降低目标；EM 责任度归一化、权重和为 1，并监测目标变化；MCMC 不允许空保留样本且拒绝会重复当前状态；概率输出有效；实验状态可分享复现。GMM 比较考虑标签置换，MCMC 不把单次短链接近真密度作为脆弱的通过条件。

浏览器验证覆盖手机布局、键盘、公式、图例、错误/空状态以及旧请求覆盖新结果的问题。上线前测量正文首屏、实验加载、控件反馈时间、计算服务 p95 和弱设备表现；本审查没有测出这些数字，不预先承诺某个框架一定更快。
