# 重构实施记录

本轮把原型升级为可运行的双语教学站，并完成现有算法入口迁移。原始长篇推导保留在旧 Streamlit 应用；新正文按“问题、直觉、数学、实验、边界、自测”重新组织。

## 已实现

- Next.js / React / TypeScript；14 个课程条目及中英文正文，共 28 个课程页面。
- 原有 11 个专题的新实验，加上 K-means；概率基础和模型评价各有独立小实验。
- MDX 与 KaTeX 数学渲染，统一目录、前置链接、上下课导航、搜索与移动导航。
- 实验主控、参数面板、分享状态、基础实验和各算法视图分别维护；算法视图不承担网络请求或 Worker 生命周期管理。
- 浏览器端 OLS、Logistic、K-means、梯度下降和 Ridge/Lasso。较重的本地计算使用 Worker。
- FastAPI 计算接口承载 NB、SVM、树、Bagging、随机森林、EM 和 MCMC；每项输入有上限。
- 拖点与方向键操作、迭代单步/回退/播放、固定种子、分享还原、解释型自测、本机学习进度。
- 旧应用修复：OLS 固定种子；GD 稳定范围；Ridge/Lasso 尺度与网格效率；EM 方差、样本数、稳定计算；MCMC 保留样本与诊断；公式字符串和分类文案。

## 设计取舍

使用 CSS 设计令牌和原生语义控件实现本轮视觉，没有为了几种控件引入整套 UI 生成工具。可以在以后需要复杂菜单/弹窗时逐步采用 shadcn/ui。图形使用 SVG，保证核心实验较小且可定制；原有复杂 Plotly 图仍在旧应用中。

首期采用一个 Next.js 项目和一个 Python 包，明确边界但不引入 monorepo 构建编排。首页英文是全站默认入口，中文通过稳定的语言路由访问；切换语言保留当前实验配置。

科学计算结果由服务返回；图表和动画在浏览器播放。没有把后端 sleep 当成动画时钟，也没有向服务端提供任意代码执行能力。

## 当前边界

- 新版 EM 按完整迭代回放，尚未细拆 E/M 子阶段；Poisson mixture 的原有深入实验保留在旧版。
- 随机森林目前使用二维教学数据，未加入高维特征重要性实验。
- 新版 SVM 有核、C/gamma、支持向量及验证表现；原版 3D 决策地形和完整对偶推导仍由旧版承载。
- OLS 有拖点、残差与训练指标；完整区间/诊断面板尚待后续课件扩展。
- 共享链接复现参数、种子与手动数据，迭代从初始帧开始；没有云端共享数据库。
- 学习进度只保存在本机；没有登录、跨设备同步或公共发布。
- 其他建议新增算法尚属于下一轮课程开发，README 列出了明确范围。

## 验证原则

数值测试检查真正的数学性质和参考结果：已知线性解、损失稳定性、留出标签不进入训练、K-means 单调目标、EM 归一化与似然、拒绝采样状态保留、API 输入边界。浏览器测试覆盖所有语言/课程、分享还原、交互、进度、手机布局和服务故障恢复。

本轮本地验证结果：

- 生产构建成功，生成 34 个静态页面；TypeScript 类型检查和格式检查通过。
- 6 项 TypeScript 测试、20 项 Python 测试、7 项浏览器测试通过。数值测试包含与 NumPy / scikit-learn 的交叉核对。
- 浏览器覆盖全部 28 个课程页面；抽查首页、OLS 和中文 K-means 的自动无障碍检查未发现违规。自动检查不能替代完整的人工无障碍审查。
- 桌面及手机截图已检查；旧版首页与 12 个页面完成启动检查，旧版 GMM / Poisson EM 和 MCMC 完成运行检查。
- 一键开发启动已验证：网页和 Python 健康检查均返回成功，退出时两个服务正常关闭。

已添加 GitHub Actions 工作流，但尚未在远端执行；以上结果来自本地环境。

框架构建、测试和本地浏览器通过不代表真实全球负载已经验证。生产部署前还需根据实际访问地区、流量、服务器资源测量首屏与计算服务延迟。
